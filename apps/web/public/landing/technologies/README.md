# Technology logo sources

FalkorDB: the unchanged color F icon from the official [FalkorDB Media Center](https://www.falkordb.com/media-center/). Its original colors and aspect ratio are preserved. The media center makes these assets available for promotional use and requests that the logo not be altered.

React, TypeScript, Vite, Python, FastAPI, LangGraph and PostgreSQL: SVG marks from [Simple Icons](https://github.com/simple-icons/simple-icons), distributed under the included CC0 license. Logos remain trademarks of their respective owners. Use here identifies Sixth's project technologies; it does not indicate sponsorship or endorsement.

Exact download URLs are recorded in `sources.json`. Files are served locally, without a remote logo CDN. The rotating layout counter-rotates each badge so logos and labels stay upright; it pauses offscreen, on hover, on keyboard focus, or with its explicit control. Reduced motion presents a static ring.
