## Method and limits

Fetched repository commit metadata and recursive file trees through GitHub's public API; fetched README, license and selected code/docs from raw.githubusercontent.com at the pinned SHA. All 15 trees were untruncated. Selection focused on runtime boundaries, memory, browser actions, graph support and interface theming. Local retrieval caches are ignored and are not published as Sixth documentation.

No dependency installation, live provider calls, upstream test suites or cross-project compatibility tests were performed. Statements about source code reflect the inspected snapshot. Roadmap statements are labeled separately from implemented behavior. Absence of a verified roadmap means the reviewed material did not establish one, not that the project has none.
